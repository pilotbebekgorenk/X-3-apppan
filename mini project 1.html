Information and Comunication Technology

Introduction

The ICT Class program helps students develop knowledge and skills in information and communication technology. Students learn how technology can be used to create websites and digital applications.

Through this program, students study several programming and database technologies. The learning activities are designed to build practical skills step by step.

Learning Topics

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL

Learning Roadmap

  1. Learn HTML
  2. Learn CSS
  3. Learn JavaScript
  4. Learn PHP
  5. Learn MySQL

Technology Definitions

HTML
HTML is used to structure the content of a webpage.
CSS
CSS is used to style and design the appearance of a webpage.
JavaScript
JavaScript is used to add interaction and dynamic behavior to webpages.

Important Announcement

Important: Students should complete each ICT learning topic before moving to the next stage.
